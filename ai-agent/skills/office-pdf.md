# PDF 文档

## 什么时候用

定稿导出、材料合并、需要防篡改的提交件、打印版。

判断标准：需要**固定版式、不再编辑**的交付物用 PDF；还在改的内容不要过早导出。

## 怎么生成

调用 `office_generate`，`format` 为 `pdf`：

```json
{
  "format": "pdf",
  "title": "参赛材料清单",
  "paragraphs": ["一、报名表", "二、项目计划书", "三、演示文稿", "四、源代码说明"]
}
```

## 材料合并的常见顺序

1. 封面（项目名、团队、日期）
2. 材料清单
3. 报名表
4. 项目计划书
5. 演示文稿打印版
6. 附录（证书、截图说明、参考文献）

每份材料之间用一个空段落分隔。

## 中文字体

- 必须嵌入中文字体；服务端默认使用 `simhei.ttf`。
- 找不到字体时会明确报错，不会输出乱码。
- 需要其它字体时设置环境变量 `ILINK_PDF_FONT` 指向 `.ttf` 文件。

## 打印与提交

- 页面默认 A4（595 × 842 pt）。
- 提交前确认文件名符合要求，例如 `iLink_项目计划书.pdf`。
- 需要签字或盖章的页面，留出空白边距。

## 常见错误

| 错误 | 修正 |
|---|---|
| 中文显示成方框 | 检查是否嵌入字体；设置 `ILINK_PDF_FONT` |
| 内容被截断 | 拆成多个短段落，或改用 docx |
| 把可编辑内容直接导出 PDF | 先定稿 docx，再导出 |
| 文件名含空格或特殊符号 | 用下划线连接 |

## 已知限制

- 只支持纯文本：不支持表格、图片、页眉页脚、超链接、书签。
- 不做自动分页排版，超长内容会截断。
- 需要复杂排版时：先生成 docx，再用办公软件导出 PDF。

## 生成后检查

1. 文件以 `.pdf` 结尾，`bytes` 大于 0。
2. 打开后中文正常显示（不是方框或乱码）。
3. 确认内容没有超出页面被截断。
