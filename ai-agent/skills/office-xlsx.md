# Excel 表格（.xlsx）

## 什么时候用

任务台账、成员分工表、材料清单、评分表、备赛排期、预算表。

判断标准：需要**逐行逐列对比或筛选**的数据用 xlsx；需要说明因果关系用 docx。

## 怎么生成

调用 `office_generate`，`format` 为 `xlsx`：

```json
{
  "format": "xlsx",
  "title": "备赛任务台账",
  "sheets": [
    {
      "name": "任务",
      "columns": [
        { "key": "task", "label": "任务", "width": 30 },
        { "key": "owner", "label": "负责人", "width": 12 },
        { "key": "status", "label": "状态", "width": 10 },
        { "key": "deadline", "label": "截止日期", "width": 14 }
      ],
      "rows": [
        { "task": "完成需求文档", "owner": "张三", "status": "进行中", "deadline": "2026-11-10" }
      ]
    }
  ]
}
```

## 常用表结构

### 任务台账

`任务 / 负责人 / 状态 / 优先级 / 截止日期 / 备注`

- 状态只用固定几个值：待办、进行中、待审核、已完成、已取消。
- 优先级用数字 1–4，1 最高。

### 材料清单

`材料名 / 是否已备 / 负责人 / 存放位置 / 截止日期`

- “是否已备”用“是 / 否”，不要用勾选符号。

### 评分表

`评分项 / 权重 / 自评 / 复核 / 说明`

- 权重写百分数或小数，全表合计 100%。

### 排期表

`阶段 / 开始日期 / 结束日期 / 产出 / 负责人`

- 日期统一 `YYYY-MM-DD`。

## 数据规范

- `columns[].key` 用英文，`label` 用中文；列宽建议 10–60。
- 日期统一 `YYYY-MM-DD`，时间统一 ISO-8601。
- 数量、金额用数字，不带单位；单位写进列名。
- 多个主题分成多个 `sheet`，单表只表达一个维度。
- 空值留空，不写“无”“N/A”之类的占位符。

## 数据安全

- 单元格文本不要以 `=`、`+`、`-`、`@` 开头，避免被当作公式执行。
- 不写外部引用、宏或链接。
- 不要把密钥、令牌、身份证号、手机号写进表格。

## 常见错误

| 错误 | 修正 |
|---|---|
| 一行里字段数和列数不一致 | 以 `columns[].key` 为准，缺的留空字符串 |
| 日期写成“11月10日” | 写 `2026-11-10` |
| 金额写“￥1,200” | 写 `1200`，单位放到列名 |
| 所有内容塞进一个 sheet | 按主题拆分 |

## 已知限制

- 当前写的是值，不写公式；需要自动计算时在 Excel 里补。
- 不支持图表、透视表、条件格式、合并单元格。
- 单个工作表名最长 31 个字符。

## 生成后检查

1. 列数与每行字段数一致。
2. 所有日期能按 ISO 解析。
3. 文件名以 `.xlsx` 结尾，`bytes` 大于 0。
