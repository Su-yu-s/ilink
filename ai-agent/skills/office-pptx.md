# 演示文稿（.pptx）

## 什么时候用

答辩、项目汇报、路演、周会汇报、竞赛答辩提纲。

判断标准：需要**讲给别人听**的用 pptx；需要别人自己读的用 docx。

## 怎么生成

调用 `office_generate`，`format` 为 `pptx`：

```json
{
  "format": "pptx",
  "title": "iLink 项目答辩",
  "slides": [
    { "title": "问题", "bullets": ["组队信息分散在群聊", "材料版本混乱", "进度不可见"] },
    { "title": "方案", "bullets": ["统一组队大厅", "资料库 + 任务看板", "Agent 工作台"] }
  ]
}
```

第一页是封面（用 `title`），后面每个元素一页。

### 用模板填充

有学院或赛事的官方 PPT 模板时优先填充：

```json
{
  "format": "pptx",
  "title": "答辩演示",
  "templatePath": "答辩模板.pptx",
  "replacements": { "projectName": "iLink", "team": "同频小队", "date": "2026-11-20" }
}
```

模板中 `ppt/slides/slideN.xml` 里的 `${key}` 会被替换；填充后忽略 `slides`，也不会新增页。

## 答辩常用结构

| 页 | 内容 | 时长 |
|---|---|---|
| 1 | 封面：题目、团队、日期 | 10 秒 |
| 2 | 问题：现状 + 痛点（3 条以内） | 1 分钟 |
| 3 | 方案：核心思路 + 架构图（用文字描述） | 2 分钟 |
| 4 | 实现：关键技术点 | 2 分钟 |
| 5 | 演示：真实界面或数据 | 2 分钟 |
| 6 | 效果：量化结果（完成率、耗时、覆盖率） | 1 分钟 |
| 7 | 总结与展望 | 30 秒 |

## 内容规范

- 每页 3–6 条要点，一条不超过 40 字。
- 标题不超过 20 字，用名词短语，不用完整句子。
- 一页只讲一个结论；细节放 Word 文档。
- 数据写成短句，例如“任务完成率 78%（12/15）”。
- 不写“谢谢聆听”“请老师批评指正”这类空页。

## 讲稿与幻灯片的分工

- docx 放完整讲稿、材料原文、参考文献。
- pptx 只放结论、关键数据、界面截图说明。
- 不要把 docx 全文粘进幻灯片。

## 常见错误

| 错误 | 修正 |
|---|---|
| 一页超过 8 条 | 拆成两页，或下沉到 docx |
| 标题是完整句子 | 改成名词短语，如“实现：检索链路” |
| 要点写成段落 | 每条控制在 40 字内 |
| 没有量化结果 | 补“完成率 / 耗时 / 覆盖题目数” |

## 已知限制

- 当前只生成“标题 + 要点”版式，不支持图片、图表、表格、模板和备注。
- 不能指定配色和字体，使用默认版式。
- 需要精美排版时，先生成提纲，再在 PowerPoint 里套模板。

## 生成后检查

1. 页数与预期一致（封面 + slides 数量）。
2. 每页要点数量在 3–6 条。
3. 文件以 `.pptx` 结尾，`bytes` 大于 0。
