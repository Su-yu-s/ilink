# Word 文档（.docx）

## 什么时候用

项目计划书、需求说明、竞赛报名材料、周报、总结报告、答辩讲稿、协作分工说明。

判断标准：需要**连续段落 + 章节结构**的交付物用 docx；纯数据用 xlsx，纯演示用 pptx。

## 怎么生成

调用 `office_generate`，`format` 为 `docx`：

```json
{
  "format": "docx",
  "title": "iLink 校园协作平台 项目计划书",
  "blocks": [
    { "type": "heading", "text": "一、项目背景" },
    { "type": "paragraph", "text": "高校竞赛组队信息分散在群聊与网盘中，缺少统一沉淀。" },
    { "type": "bullet", "text": "组队信息无法检索" },
    { "type": "table", "headers": ["阶段", "产出", "负责人", "截止"], "rows": [["需求", "PRD", "张三", "2026-11-10"]] }
  ]
}
```

块类型只有四种：`heading`、`paragraph`、`bullet`、`table`。

### 用模板填充

有正式模板时不要从零生成：

```json
{
  "format": "docx",
  "title": "项目计划书",
  "templatePath": "项目计划书模板.docx",
  "replacements": { "projectName": "iLink", "leader": "张三" }
}
```

模板中的 `${key}` 会被替换；占位符必须保持连续文本，中间不要切换格式。填充后忽略 `blocks`。

## 竞赛材料常用结构

### 项目计划书

1. 项目背景（痛点 + 现状）
2. 目标与范围（做什么、不做什么）
3. 方案设计（架构 / 模块 / 关键流程）
4. 实施计划（里程碑表）
5. 团队分工（成员表）
6. 风险与应对
7. 预算（如有）

### 周报

1. 本周完成（bullet）
2. 进行中（bullet + 预计完成时间）
3. 风险与阻塞（bullet，写清需要谁支持）
4. 下周计划（table：任务 / 负责人 / 截止）

### 报名材料说明

1. 材料清单（table：材料名 / 是否已备 / 负责人）
2. 提交要求（格式、命名、截止时间）
3. 注意事项

## 中文排版约定

- 标题不加多余空格；中英文之间保留一个空格。
- 一段只写一个意思；超过 5 行拆成多段。
- 表格列不超过 6 列；单元格不写换行。
- 金额、日期、人数写全，不用“左右”“大概”。
- 编号写进 `text` 里（当前版本不自动编号）。

## 常见错误

| 错误 | 修正 |
|---|---|
| 把整篇内容塞进一个 `paragraph` | 按章节拆成 heading + paragraph |
| 用 `table` 当分隔线 | 用 `paragraph` |
| 表格第一行不是表头 | `headers` 单独传，`rows` 只放数据 |
| 标题用普通段落加粗 | 用 `heading`，便于后续生成目录 |

## 已知限制

- 不支持图片、目录、页眉页脚、批注、超链接。
- 表格列宽按页面百分比自适应，不能逐列指定。
- 需要复杂排版时，先生成内容，再在 Word 里人工调整。

## 生成后检查

1. 返回的 `bytes` 大于 0，文件名以 `.docx` 结尾。
2. 文件落在沙箱 `workspace/`，未确认前不会进入团队资料库。
3. 上报给用户时说明文件名、用途、预计页数。
