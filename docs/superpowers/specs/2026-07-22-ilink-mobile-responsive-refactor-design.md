# iLink 全站移动端响应式重构实施记录

- 设计日期：2026-07-22
- 文档更新：2026-08-15
- 状态：已完成，用户已验收
- 采用方案：B — 整理并重构现有样式体系，不新增末尾补丁层

## 1. 目标与结果

本次重构在不改变接口、请求参数、权限判断和业务流程的前提下，为 iLink 的公开门户、个人中心、内容编辑、团队协作和管理页面建立一致的桌面、平板、移动端与小屏布局。

当前结果：

- 共享头部统一为桌面导航和移动抽屉，不再维护多套互相竞争的移动导航。
- 搜索、筛选、卡片、头像、状态标签、Toast、Modal 和表单反馈使用统一设计语言。
- 无业务价值的重置按钮已从页面移除。
- 个人中心和团队空间的重复 redesign 样式已并回主文件，旧文件停止使用并删除。
- 团队空间在移动端提供项目菜单、状态 Tab、底部任务操作和创建入口。
- Markdown 编辑器、公开列表、详情页、认证页和管理页均具备移动端规则。
- 首页保留用户已打磨的诗句、内容、区块顺序和桌面动效，只进行配色、响应式与可访问性适配。

## 2. 不变约束

以下规则在后续维护中继续有效：

1. 不因视觉或响应式调整修改 Controller、Service、Mapper、数据库迁移、API URL、HTTP 方法、请求体或响应解析。
2. 不重写现有登录、身份权限、发布、申请、任务状态、聊天和附件上传流程。
3. 只为响应式交互增加展示层状态，例如抽屉开关、移动看板状态 Tab、编辑/预览模式和拖拽禁用判断。
4. 桌面端核心信息层级和入口保持稳定。
5. 首页是受保护区域：诗句、内容、区块顺序和叙事动画不得被通用门户方案替换。

## 3. 当前样式架构

| 文件 | 当前职责 |
| --- | --- |
| `design-tokens.css` | 色彩、字体、间距、圆角、阴影、层级和公共尺寸变量 |
| `layout.css` | 页面容器、通用栅格、侧栏和基础响应式布局 |
| `components.css` | 头部、按钮、表单、卡片基础、Toast、Modal、标签和状态 |
| `effects.css` | 装饰动效、触摸设备降级和减少动效规则 |
| `style.css` | 仍需兼容的全局基础样式 |
| `app-redesign.css` | 全站冷灰主题的公共外观，不承担页面专属结构 |
| `portal-redesign.css` | 公开门户的共享结构和视觉规则 |
| `search-bar.css` | 搜索输入、筛选器和操作区的统一布局 |
| `profile.css` | 个人中心及其响应式规则 |
| `team-space.css` | 团队工作台、Kanban、项目菜单和移动操作 |
| `md-editor.css` | Markdown 工具栏、编辑/预览布局和内容防溢出 |
| 其他页面 CSS | 对应页面独有结构和变体 |

已删除的重复样式：

- `home-redesign.css`
- `profile-redesign.css`
- `team-space-redesign.css`

共享模板使用 `fragments/header.html`、`fragments/profile-sidebar.html`、`fragments/search-field.html` 等片段，避免各页面继续复制结构。

## 4. 响应式基线

| 模式 | 视口 | 基本规则 |
| --- | --- | --- |
| 桌面 | `>1024px` | 保留完整导航、多列内容和桌面协作能力 |
| 平板 | `768–1024px` | 主要网格收为两列，适当收窄间距和侧栏 |
| 移动 | `<768px` | 单列、全宽、触摸优先，使用移动抽屉和状态 Tab |
| 小屏 | `<480px` | 进一步收紧卡片 padding 和字号，筛选器改为单列 |

宽度正好 768px 按平板处理。页面级横向溢出应通过修正真实宽度解决；代码块、表格、标签栏和工具栏允许在自身容器内滚动。个别页面仍存在局部 `overflow-x: hidden` 作为容器裁切，不能以此代替溢出验收。

## 5. 共享导航

- 所有带全站头部的页面使用 `fragments/header.html`。
- 移动端头部按 56px 基线并计入 `env(safe-area-inset-top)`。
- Logo 位于左侧，右侧保留通知、用户入口和 44×44 菜单按钮。
- 菜单从右侧抽屉展开，登录/注册或个人中心/退出位于独立区域。
- 点击链接、遮罩或 Escape 均可关闭；脚本同步 `aria-expanded`，并在关闭后恢复焦点。
- 导航脚本只维护展示状态，不改变路由或发起业务请求。

## 6. 页面与组件落地

### 搜索与筛选

- 移动端搜索输入独占一行，图标和占位文字使用固定间距，不再重叠。
- 筛选器在中等移动宽度尽量两列，小屏收为单列。
- 搜索、发布等动作进入独立操作区域，触摸高度不少于 44px。
- 页面不再显示无实际用途的重置按钮。
- 社区和竞赛标签允许在局部横向滚动。

### 卡片与状态

- 组队、导师、成果在移动端单列；竞赛按桌面三列、平板两列、移动一列收缩。
- 头像使用固定尺寸和 `object-fit`，避免详情卡片中被原图尺寸撑开。
- 卡片主要通过边框、留白和轻阴影分层；触摸设备关闭 hover 上浮。
- “招募中”使用绿色正向状态，“已组队”“已结束”使用灰色稳定状态；错误和危险操作使用红色。

### 团队空间与 Kanban

- 移动端隐藏固定侧栏，通过“项目菜单”打开团队导航。
- “待办 / 进行中 / 待审核 / 已完成”状态 Tab 一次显示一列。
- 任务卡在移动布局中关闭拖拽，通过底部操作面板更新状态。
- 负责人可使用移动端创建任务入口；底部操作计入安全区。
- 桌面端保留四列布局和拖拽。

### 编辑器与 Markdown

- 移动端以单栏编辑为主，可切换预览。
- 工具栏可在自身容器横向滚动，控件满足触摸尺寸。
- 代码块和表格局部滚动，图片不超过内容宽度。
- 桌面端继续支持更完整的编辑与预览布局，保存和上传流程不变。

### 个人中心

- 所有个人中心页面共用 `profile-sidebar` 片段。
- 移动端侧栏转换为顶部可横向滚动的导航。
- 教师与学生使用角色化资料标签；教师不展示年级。
- 表单、Toast、Modal、通知和关闭按钮统一处理触摸尺寸与安全区。

### 首页

- 保留古诗文案、图片区块、CTA、区块顺序和原有跳转。
- 保留逐字进入、滚动揭示、视差、粒子与磁吸等桌面动效。
- `prefers-reduced-motion` 下关闭非必要动画；移动端降低动效密度。
- 后续只允许配色、响应式和无障碍层面的必要调整。

## 7. 资源与性能原则

- 非首屏内容图片优先使用 `loading="lazy"` 和 `decoding="async"`。
- 只有 `(hover: hover) and (pointer: fine)` 的设备启用 hover 反馈。
- `prefers-reduced-motion: reduce` 关闭非必要动画。
- 不为响应式重构引入新的前端框架。
- 列表加载应避免重复请求；团队空间任务数据一次加载后在内存中分组和统计。

## 8. 验证清单

2026-08-15 发布回归已自动验证 393px、768px、1280px：组队、竞赛、成果及公开详情无页面级横向溢出，可见按钮、输入框和选择器满足 44px 触控高度；浏览器控制台无可操作错误。375px、1024px 仍作为后续人工抽检基线。

后续修改涉及共享样式时，至少回归 375px、393px、768px、1024px 和 1280px，并检查：

1. `document.documentElement.scrollWidth <= document.documentElement.clientWidth + 1`。
2. 移动端单列、平板两列、桌面布局与各页面约定一致。
3. 可见触摸目标不小于 44px，移动表单输入字号不小于 16px。
4. 抽屉的当前项、遮罩、Escape、焦点恢复和 `aria-expanded` 正确。
5. 搜索图标、占位文字、按钮图标、头像和状态标签没有错位。
6. 团队空间移动端一次只显示一个状态，拖拽关闭，操作面板可用。
7. 编辑器的代码、表格和图片不撑宽页面。
8. 首页诗句、内容顺序和桌面动效没有被替换或删除。
9. 浏览器控制台无新增错误，关键请求 URL、方法和响应处理未改变。
10. Maven 测试和路径契约测试通过。

## 9. 回退边界

若后续组件调整造成桌面端回退，只回退该组件的样式迁移，不通过增加更高优先级的文件尾补丁掩盖问题。不得恢复已删除的 redesign 文件，也不得重新复制共享头部、个人中心侧栏或搜索组件。
