# 个人资料奖项证明缩略图设计

## 目标

在“个人资料”阅读视图的奖项卡片中展示获奖等级和证明材料预览，使用户无需进入编辑模式即可确认奖项级别及其证明文件。

## 范围

- 只调整 `/profile-edit.html` 的“个人奖项”阅读卡片。
- 复用现有奖项数据中的 `level`、`proofUrl`、`issuer`、`period` 字段，不修改数据库或接口结构。
- 不改变奖项编辑弹窗、个人成果页和公开主页的现有交互。

## 卡片布局

每条奖项采用紧凑的三段布局：

1. 左侧为证明材料预览区。图片显示 64 × 64 像素缩略图；PDF 或普通链接显示对应的文件图标卡；无证明材料时不渲染该区域。
2. 中间为奖项名称和等级徽标。等级映射为“国际级、国家级、省级、校级、其他”，未填写等级时不显示空徽标。
3. 右侧保留颁发机构与时间，二者使用中点分隔；字段缺失时只显示已有内容。

图片缩略图使用裁切填充，不拉伸原图。点击图片、PDF 卡或链接卡会在新标签页打开原始证明材料。

## 状态与容错

- 图片采用延迟加载，并保留原始地址用于一次安全编码重试。
- 图片仍加载失败时，替换为“证明材料”占位图标，不显示破损图片。
- PDF 使用醒目的 `PDF` 标识；无法识别的链接使用通用附件图标。
- 所有来自用户数据的文字与 URL 均经过现有转义和安全 URL 处理。

## 视觉与响应式

- 延续当前黑白灰的克制配色，等级徽标使用现有低饱和层级样式，不引入新的高饱和强调色。
- 桌面端缩略图为 64 × 64 像素，奖项标题与等级占据主要空间。
- 小屏幕缩略图缩为 52 × 52 像素，颁发机构与时间移到内容区下方并允许换行。
- 可点击预览提供可见焦点状态和描述性 `aria-label`。

## 验证

- 契约测试确认阅读卡片输出等级与证明材料结构。
- 浏览器回归覆盖图片、PDF、普通链接、无证明和图片加载失败五种状态。
- 在 393、768、1280 像素宽度下验证无横向溢出，缩略图比例和信息层级正确。
