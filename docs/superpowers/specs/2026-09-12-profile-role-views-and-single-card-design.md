# 个人中心角色视图与单卡片资料页设计

## 目标

修复教师端点击“我的团队”无响应的问题，并明确教师端“竞赛概览”和“我的团队”的内容边界。同时统一教师端、学生端个人资料页的阅读态与编辑态布局，将分散的视觉卡片收敛为一张大卡片，内部用分割线组织信息。

## 一、教师端竞赛概览与我的团队

### 竞赛概览

- 地址保持 `/profile.html`，侧栏选中“竞赛概览”。
- 展示个人身份摘要、导师资料、竞赛成果和荣誉奖项。
- 不展示团队列表、组队申请、团队操作按钮或发布团队入口。
- 成果与奖项复用当前用户数据及现有荣誉字段；无内容时显示“未填写”或对应空态，不混入团队数据。

### 我的团队

- 地址保持 `/profile.html#teams`，侧栏选中“我的团队”。
- 隐藏导师资料、竞赛成果和荣誉奖项概览，只展示教师创建或参与的团队项目。
- 保留团队卡片已有的进入团队、查看详情、邀请成员等权限相关操作。
- 直接访问或刷新 `/profile.html#teams` 时必须正确恢复团队视图。
- 从“我的团队”返回“竞赛概览”时恢复概览内容，并再次隐藏团队区域。

### 角色边界

- 教师端不再无条件隐藏团队区域，而是根据当前 hash 选择视图。
- 学生端现有竞赛概览与我的团队行为保持不变，避免引入回归。

## 二、个人资料页单卡片结构

### 页面骨架

`/profile-edit.html` 保留现有侧栏和“阅读 / 编辑”状态切换。右侧内容区只保留一张主卡片，卡片内部依次排列：

1. 身份摘要：头像、姓名或用户名、角色标签、学校/任职单位与院系。
2. 基本信息：用户名、姓名、邮箱、性别、学校/任职单位、专业/专业领域、学院/部门；学生额外显示年级。
3. 个人简介。
4. 导师资料：仅教师显示职称、研究方向、导师简介和代表项目。
5. 技能标签。
6. 个人奖项。

各区块使用一条浅色分割线区隔，不再为区块添加独立背景、边框或阴影。主卡片统一圆角、边框和内边距。

### 阅读态

- 默认进入阅读态。
- 信息采用标签和值的网格排版；桌面端优先三列，窄屏逐步降为两列和一列。
- 空字段统一显示“未填写”，不留空白。
- 技能与奖项沿用现有数据、等级标签和证明材料缩略图。
- 顶部保留唯一的“编辑资料”按钮。

### 编辑态

- 点击“编辑资料”后，在同一张主卡片内切换为编辑表单，不跳转、不拆卡。
- 表单区块顺序与阅读态一致，教师专属字段只对教师显示，学生年级只对学生显示。
- 技能与奖项的添加、管理、证明材料上传逻辑保持不变，只调整容器和间距。
- 保存成功后回到阅读态；取消编辑恢复原数据。

## 三、实现边界

- 不新增后端接口，不修改用户、导师、技能、奖项的数据结构。
- 不改变侧栏信息架构和现有 URL。
- 优先复用现有 DOM 节点与 JavaScript 数据填充逻辑，只增加明确的角色视图切换函数并调整模板/CSS 结构。
- 不在本次范围内重做“个人成果”独立管理页。

## 四、验证

1. 教师在 `/profile.html` 只能看到竞赛概览内容，看不到团队内容。
2. 教师点击“我的团队”后 URL 变为 `#teams`，团队列表可见，概览内容不可见。
3. 刷新 `#teams` 页面后状态保持正确，点击“竞赛概览”可恢复。
4. 学生端两个入口继续正常工作。
5. 教师与学生的 `/profile-edit.html` 默认均为单卡片阅读态，字段符合各自角色。
6. 两种角色均可进入编辑态、保存并返回阅读态，技能与奖项交互无回归。
7. 桌面端和移动端不出现横向滚动、重叠或被分割线切断的内容。
